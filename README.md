# Flipper Hackspace wiki

The members' wiki. [Docusaurus 3](https://docusaurus.io), docs-only mode, deployed on its own Netlify site.

```bash
npm install
npm run dev      # http://localhost:3000/
npm run build    # static site in build/
```

## Netlify

`netlify.toml` sets the build. Connect this repo and leave the defaults:

| Setting | Value |
|---|---|
| Build command | `npm run build` |
| Publish directory | `build` |
| Node | 22 |

Netlify's `URL` becomes the canonical site address at build time. Set `WIKI_SITE_URL` only if that should be a different host.

Every page has an "Edit this page" link to this repo. Override it with `WIKI_EDIT_URL` if the branch or path changes.

## Layout

| | |
|---|---|
| `docs/` | All content. The sidebar is **generated from this tree** — add a file, it appears. |
| `docs/*/_category_.json` | Section label, position, and the doc its heading links to. |
| `sidebars.ts` | One autogenerated sidebar. Deliberately nothing to maintain here. |
| `docusaurus.config.ts` | Site config, navbar, footer, search. |
| `src/css/custom.css` | Infima overrides — the landing page's tokens, duplicated. |
| `static/img/` | Mark, favicon, and Open Graph image. |

## Conventions

Both of these are enforced by the build, which fails rather than warns:

- **Links between pages are relative and include `.md`** — `[matrix](../safety/induction-matrix.md)`.
  `onBrokenLinks` and `onBrokenAnchors` are both `throw`: a dead link in a safety page is worse
  than a failed deploy.
- **Frontmatter is `title`, `sidebar_position`, `description`.** Docusaurus validates docs
  frontmatter strictly, so tool metadata (maintainer, induction, status) goes in a table in the
  page body rather than in custom frontmatter keys.

Content conventions — what to mark as unverified, what needs review before it lands, what must
never go on the wiki — are documented for contributors in `docs/contributing.md`.

Search is local-only. `@easyops-cn/docusaurus-search-local` indexes at build time; nothing
leaves the browser and there are no Algolia keys to manage.
