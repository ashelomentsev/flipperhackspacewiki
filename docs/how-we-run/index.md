# How we run

The governance pages. Shorter than most spaces' and deliberately honest about one thing.

- **[Membership](./membership.md)** — tiers, what it obliges you to, notice, and withdrawal.
- **[Code of conduct](./code-of-conduct.md)** — binding, with a reporting route that is not
  Telegram.
- **[How decisions get made](./how-decisions-get-made.md)** — who decides what, and where the
  limits are.

## The thing to be honest about

**This is not a member-run hackspace.** It is a company-run space: Flipper Technologies Ltd holds
the lease, owns the kit, sets the prices and has the final say. Membership is by application and
can be withdrawn.

That is a real difference from a co-operative hackspace, and it cuts both ways. You get four
floors of commercial-grade equipment, 24/7 access, and the firmware team upstairs — none of which
a volunteer-run space could fund. What you do not get is a vote on how the space is run.

Both are legitimate models. Knowing which one you have joined prevents the specific
disappointment of expecting the other.

See [How decisions get made](./how-decisions-get-made.md) for where members genuinely do decide
things, which is more than it might sound.
