# Who to contact

Nearly everything goes to the members' Telegram. This page is about the exceptions.

## By problem

| Problem | Where |
| --- | --- |
| Broken tool, or one behaving oddly | The tool's page names its maintainer — tell them **and** post in Telegram |
| Need an induction | [Getting inducted](../safety/getting-inducted.md) |
| Locked out, card not working | Members' Telegram, right away |
| Lost card | Members' Telegram **immediately**, so it can be revoked |
| Out of a consumable | Members' Telegram |
| Injury, fire, near miss | [Incidents & first aid](../safety/incidents-and-first-aid.md) — and it gets logged, always |
| Code of conduct concern | [Code of conduct](../how-we-run/code-of-conduct.md) has the reporting route, including one that is not Telegram |
| Something that needs a decision | [How decisions get made](../how-we-run/how-decisions-get-made.md) |
| Billing, membership, notice | [hackspace@flipper.net](mailto:hackspace@flipper.net) |
| Want to run an event | [Propose an event](../events/propose-an-event.md) |
| Press, filming, visits | [hackspace@flipper.net](mailto:hackspace@flipper.net) — not Telegram |

## The channels

**Members' Telegram** — [@flipper_hackbot](https://t.me/flipper_hackbot) is the way in. This
is where day-to-day everything happens: tool status, who has a spare STM32 tonight, session
announcements, and the pinned post with the things that are deliberately not on this public
wiki.

**Email** — [hackspace@flipper.net](mailto:hackspace@flipper.net) for anything
administrative, anything involving money, and anything you would rather not put in a group
chat.

**Phone** — [+44 7462 104288](tel:+447462104288). For urgent and in-person. Not for
questions that can wait.

**999** — fire, or an injury beyond a plaster. Call first, tell the Telegram second. Nobody
has ever been criticised here for calling an ambulance that turned out not to be needed.
