# Guides

One page per subsystem. Each one covers what it does, what it is genuinely useful for at a
hackspace, and where [Responsible use](../responsible-use.md) applies — which for three of
these is most of the page.

| Guide | Good for | Policy weight |
| --- | --- | --- |
| [Sub-GHz](./sub-ghz.md) | Your own fobs and sensors, protocol work | **High** — transmitting is regulated |
| [NFC & RFID](./nfc-and-rfid.md) | Your own cards, understanding credentials | **High** — credentials and personal data |
| [Infrared](./infrared.md) | Remotes, learning protocols | Low, until it isn't |
| [GPIO & modules](./gpio-and-modules.md) | Your own hardware. The best one | None |
| [BadUSB](./badusb.md) | Your own machines, automation | **High** — unauthorised access |

## If you are new

Start with [GPIO & modules](./gpio-and-modules.md). It is the subsystem with no policy
implications, the most use at a bench, and it teaches you the device on hardware you own.

## A note on the shape of these pages

These are **starting points, not references**. The
[official documentation](https://docs.flipper.net) is the reference and it is good; these pages
exist to say what is worth doing here, with this kit, under this policy.

If you work something out that is not written down, write it down. See
[Editing this wiki](../../contributing.md).
