Full-size slotted, Phillips and Torx screwdrivers on the wall rack.

**Hang each back in its marked slot.** The rack is marked so a missing tool is visible at a
glance, which only works if people use the right slot rather than the nearest one.

## Don't

- **Don't use a screwdriver as a chisel, pry bar or punch.**
- **Don't take them off the bench.** Hand tools stay in the building — see
  [House rules](../../start-here/house-rules.md).

## If it breaks

A chewed tip or a split handle: report it, don't re-hang it.
