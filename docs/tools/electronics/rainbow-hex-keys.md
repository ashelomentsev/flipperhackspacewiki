Metric hex keys, **1.5–10 mm**, one colour per size.

- **Ball end** works at an angle, for awkward spots.
- **Straight end** for tightening hard, or breaking a stuck bolt loose. The ball end will round
  out a socket if you lean on it.

Clip them back into the holder **in size order**.

## Don't

- **Don't lean on the ball end.** That is how hex sockets get rounded, and a rounded socket is a
  drill-out.
- **Don't use metric on imperial.** A 5 mm key in a 3/16" socket feels nearly right and will
  wreck both.

## If it breaks

A rounded or twisted key gets reported — one missing size makes the set much less
useful than it sounds.
