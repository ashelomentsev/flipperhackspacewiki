Tiny drivers for electronics: **Torx** (TX5, TX6 and others), **slotted** (1.5, 1.8,
2.0 mm) and **Phillips**. Colour rings show the type; the size is printed on the handle.

## How to use

1. Pick the size that **fills the screw head fully**. An undersized driver rounds the head out,
   and then the screw is a drilling job.
2. Spin the cap on top with one finger while turning the handle with the others — that is what
   the rotating cap is for.
3. Return each driver to **its own slot** and roll the pouch closed.

## Don't

- **Don't use them as levers, picks or chisels.** The tips are hard and they snap.
- **Don't leave the pouch open on the bench.** Half the set ends up in a project box.

## If it breaks

A rounded or snapped tip means that size is gone — post it in the hackspace channel
so it gets replaced. Don't just put it back.
