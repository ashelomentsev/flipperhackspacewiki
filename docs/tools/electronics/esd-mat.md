The grey anti-static mat drains static safely.

**Clip a wrist strap to the round metal snap stud before handling bare boards.** This is
[bench rule 4](./index.md#bench-rules).

ESD damage mostly does not announce itself. It degrades a part that then fails next week in
someone's project, which is why the rule is absolute rather than risk-assessed each time.

## Don't

- **Don't cut on it.** A cut mat no longer conducts across the cut.
- **Don't put hot tools on it.** It melts, and then it has a hole in it.
- **Don't put it away.** It lives on the bench.
